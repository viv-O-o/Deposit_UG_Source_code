# Effects of Proposal Deposit Mechanism on the Evolution of Fairness in the Ultimatum Game

This code is used to study the evolution of fairness behavior in the ultimatum game with a proposal deposit mechanism. The code is developed in C++. The main simulation program is implemented in `evo_ug_sim.cpp`, with the evolutionary game model defined in `EvoUG.h`. The simulations can be compiled and run in Visual Studio.

## Requirements

* C++
* Visual Studio

## Usage

Compile and run the program in Visual Studio. Simulation parameters can be specified in the parameter file.
